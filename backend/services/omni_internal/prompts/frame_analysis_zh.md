你是一个影视镜头分析专家。请根据提供的视频关键帧（按时间顺序）和字幕内容，对该镜头进行语义理解。

【要求】
1. 综合多帧信息，不要只描述单帧
   - 当前通常会提供同一镜头在 1/4 与 3/4 位置截取的两帧（按时间顺序）
2. 优先识别人物、动作、场景、情绪
3. 如果字幕提供了语义，结合字幕理解
4. 输出必须为结构化 JSON
5. 所有字段内容必须使用中文输出，禁止夹杂英文（专有名词或品牌名无法翻译时除外）
6. desc和brief内容是可以重复的

【输出字段定义】
- desc：这是影片一个镜头的两帧，详细描述一下这个镜头的所有有效信息
- brief：100字以内，描述这个影视画面，包含主体人物与动作、环境与背景、字幕与剧情暗示等信息（自然语言）
- objects：画面中主要物体（数组）
- action：核心动作（动词，如：离开/奔跑/对话）
- scene：场景（室内/室外/街道/房间等）
- emotion：整体情绪（如：开心/悲伤/紧张/平静）

字幕：
{subtitle_text}

【输出 JSON 格式】
{
  "desc": "",
  "brief": "",
  "objects": [],
  "action": "",
  "scene": "",
  "emotion": ""
}
