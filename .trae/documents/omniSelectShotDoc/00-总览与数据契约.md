# Omni 脚本镜头选择与配音改造总览

## 目标

为 `project.project_type === "omni"` 的解说脚本编辑区增加类似截图中的校对工作台：

- 左侧播放当前选中的脚本片段。
- 右侧展示解说脚本列表。
- 每条脚本可以选择/替换镜头，解决自动匹配镜头不准的问题。
- 选择镜头时优先展示该条文案匹配出的精选候选镜头，目标 30 个；其它全量镜头排在后面。
- 支持单条配音和一键全部配音；单条配音优先级高于全部配音和后续视频/剪映生成。

## 现有事实

- Omni 脚本生成入口：`backend/services/omni_generate_script_service.py`。
- Omni 脚本路由：`backend/routes/omni_generate_script_routes.py`。
- 当前 Omni 脚本编辑组件：`frontend/src/components/projectEdit/omni/OmniFullNarrationScriptWorkspace.tsx`。
- Omni 生成步骤挂载点：`frontend/src/components/projectEdit/ProjectEditGenerateStep.tsx`。
- 多模态镜头结果现有接口：`GET /api/projects/{project_id}/omni/multimodal-result`。
- 当前脚本保存接口：`POST /api/projects/{project_id}/script`，保存到 `project.script`。
- 下游生成视频和剪映草稿读取 `project.script.segments[].start_time/end_time/text/OST`。

## 新增数据契约

### ScriptSegment 扩展字段

在不破坏现有字段的前提下，允许 `script.segments[]` 增加以下可选字段：

```ts
interface OmniScriptSegmentExtra {
  shot_id?: number | string;
  shot_source?: "auto" | "manual";
  tts_audio_path?: string;
  tts_audio_duration?: number;
  tts_source?: "manual" | "bulk";
  tts_text_hash?: string;
  tts_updated_at?: string;
}
```

实现要求：

- `start_time/end_time` 仍是剪辑和预览的最终依据。
- `shot_id` 只用于 UI 回显和追踪，不作为下游剪辑唯一依据。
- `tts_audio_path` 只有在文件存在且 `tts_text_hash` 与当前 `text` 匹配时才有效。
- `tts_source === "manual"` 的有效配音不能被一键全部配音覆盖。

### 候选镜头返回结构

新增候选镜头接口返回结构：

```ts
interface OmniShotOptionsResponse {
  segments: Array<{
    segment_id: string;
    preferred_shots: OmniSelectableShot[];
    other_shots: OmniSelectableShot[];
  }>;
}

interface OmniSelectableShot {
  shot_id: number | string;
  start: number;
  end: number;
  duration?: number;
  subtitle_full_text?: string;
  visual?: {
    brief?: string;
    desc?: string;
    action?: string;
    emotion?: string;
  };
  summary?: string;
  score?: number;
  final_score?: number;
  embedding_score?: number;
  rerank_score?: number;
  continuity_score?: number;
  reason?: string;
  option_source: "preferred" | "other";
}
```

实现要求：

- `preferred_shots` 优先来自 `rerank.json` 或 `global_path.json` 的 `results[].matches`。
- 推荐候选最多 30 个，按 `final_score/score` 降序。
- `other_shots` 来自 Omni 多模态全量 `shots`，排除已经在推荐候选中的 `shot_id` 后按时间排序。
- 如果推荐候选不足 30 个，展示实际数量，不强行补假数据。
