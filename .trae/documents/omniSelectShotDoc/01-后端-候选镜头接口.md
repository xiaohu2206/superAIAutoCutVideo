# 后端开发清单：Omni 候选镜头接口

## 目标

为前端镜头选择弹窗提供稳定数据源：每条脚本优先展示文案匹配出的精选候选镜头，目标 30 个；其它全量镜头排在后面。

## 涉及文件

- `backend/routes/omni_generate_script_routes.py`
- `backend/services/omni_generate_script_service.py`
- `backend/modules/omni_generate_script/pure.py`
- `backend/services/omni_shot_match_service.py`
- `backend/routes/omni_shot_match_routes.py`
- `backend/modules/projects_store.py`
- `frontend/src/services/projectService.ts`
- `frontend/src/types/project.ts`
- `frontend/src/types/omniMultimodal.ts`

## 开发任务

### 1. 调整镜头匹配候选数量

- 将 Omni shot match 的候选保留数量从当前默认值调整到 30。
- 确认 `rerank.json` 的 `results[].matches` 不被截断到小于 30。
- 保留原有分数字段：`score/final_score/embedding_score/rerank_score/continuity_score/reason`。
- 如果后端全局路径搜索使用 `rerank.json` 作为输入，保持 `global_path.json results[].matches` 也能携带推荐候选。

### 2. 新增候选镜头接口

新增路由：

```http
GET /api/projects/{project_id}/omni/generate-script/shot-options
```

返回：

```json
{
  "message": "获取候选镜头成功",
  "data": {
    "segments": [
      {
        "segment_id": "1",
        "preferred_shots": [],
        "other_shots": []
      }
    ]
  },
  "timestamp": "..."
}
```

实现要求：

- 仅允许 `project_type === "omni"`。
- 读取 `project.script.segments`；无脚本时返回空列表。
- 推荐候选优先使用 `project.omni_global_path_search_path`，不存在时使用 `project.omni_shot_match_rerank_path`。
- 全量镜头读取 `project.omni_multimodal_json_path`，使用现有 `read_multimodal_json`。
- 接口只返回前端需要展示的轻量字段，不返回 embedding。

### 3. segment 与文案匹配结果的归属规则

实现一个确定性映射函数：

- `OST=0` 解说段按 `id` 顺序映射到 `results[]`。
- 如果脚本条数与 `results[]` 不一致，优先用文本近似匹配：
  - 规范化空白后，用 `segment.text` 在 `result.text` 中包含关系判断。
  - 找不到时用相邻顺序兜底。
- `OST=1` 原声段不对应文案匹配结果：
  - `preferred_shots` 使用当前 `start_time/end_time` 附近的 5-10 个镜头。
  - `other_shots` 仍使用全量剩余镜头。

### 4. 候选镜头字段归一

后端统一输出字段：

- `shot_id`
- `start`
- `end`
- `duration`
- `subtitle_full_text`
- `visual`
- `summary`
- `score`
- `final_score`
- `embedding_score`
- `rerank_score`
- `continuity_score`
- `reason`
- `option_source`

字段来源规则：

- `start/end` 优先取 match 自身字段；缺失时用 `shot_id` 回查多模态 `shots`。
- `visual/subtitle_full_text` 优先从多模态 `shots` 补齐。
- `option_source` 后端分别标记为 `preferred` 或 `other`。

### 5. 脚本辅助字段兼容

- `projects_store.save_script` 不需要限制新增字段，只要 `script` 是 dict 且包含 `segments`。
- TypeScript `ScriptSegment` 增加可选字段：
  - `shot_id`
  - `shot_source`
  - `tts_audio_path`
  - `tts_audio_duration`
  - `tts_source`
  - `tts_text_hash`
  - `tts_updated_at`

## 验收标准

- 已完成 Omni 镜头匹配的项目，请求 `shot-options` 能返回每条脚本的候选镜头。
- 推荐区候选数量最多 30，分数高的排前面。
- 全量镜头区不重复展示推荐区已有 `shot_id`。
- 未完成镜头匹配但已有多模态结果时，接口仍能返回 `other_shots`。
- 接口返回中不包含 embedding 大数组。
