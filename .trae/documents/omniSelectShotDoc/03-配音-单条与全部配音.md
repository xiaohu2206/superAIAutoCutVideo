# 开发清单：单条配音与一键全部配音

## 目标

在 Omni 脚本工作区提供单条配音和一键全部配音能力。用户已经生成的单条配音拥有最高优先级，后续全部配音、生成视频、生成剪映草稿都不能覆盖有效单条配音。

## 涉及文件

- `backend/routes/omni_generate_script_routes.py`
- `backend/services/omni_generate_script_service.py`
- `backend/services/video_generation_service.py`
- `backend/services/jianying_draft_manager.py`
- `backend/modules/tts_service.py`
- `frontend/src/components/projectEdit/omni/OmniFullNarrationScriptWorkspace.tsx`
- `frontend/src/services/projectService.ts`
- `frontend/src/types/project.ts`

## 数据字段

在 `script.segments[]` 中保存：

```json
{
  "tts_audio_path": "/uploads/omni_script_tts/{project_id}/seg_0001.mp3",
  "tts_audio_duration": 3.42,
  "tts_source": "manual",
  "tts_text_hash": "sha256...",
  "tts_updated_at": "2026-05-21T..."
}
```

字段含义：

- `tts_source = manual`：用户点击单条配音生成。
- `tts_source = bulk`：一键全部配音生成。
- `tts_text_hash`：基于当前 segment `text` 计算，文本变化后旧音频失效。

## 后端开发任务

### 1. 单条配音接口

新增：

```http
POST /api/projects/{project_id}/omni/script/segments/{segment_id}/tts
```

行为：

- 仅允许 Omni 项目。
- 仅允许 `OST=0` 且 `text` 非空的 segment。
- 使用当前激活 TTS 配置合成音频。
- 音频落盘到 `uploads/omni_script_tts/{project_id}/manual/seg_{id}_{hash}.mp3`。
- 更新对应 segment：
  - `tts_audio_path`
  - `tts_audio_duration`
  - `tts_source = "manual"`
  - `tts_text_hash`
  - `tts_updated_at`
- 保存回 `project.script`。

### 2. 一键全部配音接口

新增：

```http
POST /api/projects/{project_id}/omni/script/tts/run
```

行为：

- 异步任务，scope：`omni_script_tts`。
- 只处理 `OST=0` segment。
- 跳过有效 `tts_source === "manual"` 的 segment。
- 覆盖无效音频、无配音、或 `tts_source === "bulk"` 的旧音频。
- 音频落盘到 `uploads/omni_script_tts/{project_id}/bulk/seg_{id}_{hash}.mp3`。
- 通过现有任务进度体系返回进度和日志。

### 3. 有效音频判断

封装公共函数：

```py
def is_valid_segment_tts(segment: dict) -> bool:
    ...
```

必须同时满足：

- `tts_audio_path` 非空。
- 文件存在。
- `tts_text_hash` 等于当前 `text` 的 hash。
- `tts_audio_duration > 0`，或可通过 ffprobe 读出时长。

### 4. 下游生成复用

修改：

- `backend/services/video_generation_service.py`
- `backend/services/jianying_draft_manager.py`

规则：

- 对 `OST=0` segment，先检查有效 `tts_audio_path`。
- 有效时直接使用该音频，不调用 `tts_service.synthesize`。
- 无效时保持现有临时 TTS 生成逻辑。
- `OST=1` 仍走原片声音，不使用 TTS。

## 前端开发任务

### 1. 单条配音按钮

在脚本行中展示：

- 未配音：`单条配音`
- 正在生成：loading
- 已配音：`试听`、`重新配音`
- 文本变更导致 hash 不匹配：`需重新配音`

点击单条配音：

- 调用单条配音接口。
- 成功后更新 `editedScript`。
- 自动播放生成的音频用于试听。

### 2. 一键全部配音按钮

工作区顶部新增按钮：

- 文案：`一键全部配音`
- 禁用条件：
  - 无脚本。
  - 没有可配音的 `OST=0` segment。
  - 正在保存脚本或已有配音任务运行。

点击后：

- 调用全部配音任务接口。
- 展示进度条和最新日志。
- 任务完成后刷新项目并更新 `editedScript`。

### 3. 配音优先级提示

顶部或按钮旁展示简短提示：

> 单条配音不会被一键全部配音覆盖。

不要弹确认框，除非用户点击“重新配音”覆盖当前单条配音。

## 验收标准

- 单条配音完成后，segment 保存 `tts_source = manual`。
- 再执行一键全部配音，manual 音频不被覆盖。
- bulk 音频可以被下一次一键全部配音覆盖。
- 修改文本后旧音频显示“需重新配音”，下游生成不复用旧音频。
- 生成视频和生成剪映草稿都优先使用有效 `tts_audio_path`。
