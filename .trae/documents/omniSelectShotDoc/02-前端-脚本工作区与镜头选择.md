# 前端开发清单：Omni 脚本工作区与镜头选择

## 目标

把 Omni 脚本 JSON 显示区改造成镜头校对工作区：左侧预览当前片段，右侧编辑脚本列表，每条都可打开镜头选择弹窗并替换镜头。

## 涉及文件

- `frontend/src/components/projectEdit/ProjectEditGenerateStep.tsx`
- `frontend/src/components/projectEdit/omni/OmniFullNarrationScriptWorkspace.tsx`
- `frontend/src/components/projectEdit/ScenePlayModal.tsx`
- `frontend/src/services/projectService.ts`
- `frontend/src/types/project.ts`
- `frontend/src/types/omniMultimodal.ts`

## 开发任务

### 1. 组件入参调整

`OmniFullNarrationScriptWorkspace` 增加：

```ts
project: Project;
```

从 `ProjectEditGenerateStep.tsx` 传入当前 `project`。

### 2. 脚本解析与兜底

- 从 `editedScript` 解析 `VideoScript`。
- 成功时展示结构化工作区。
- 失败时展示错误提示和原始 JSON textarea，避免用户内容丢失。
- 每次结构化修改后重新生成格式化 JSON 并调用 `setEditedScript`。

### 3. 左侧片段预览

左侧固定区域包含：

- 视频播放器。
- 当前片段序号、时间段、时长。
- 当前解说文本。
- 当前镜头 `shot_id`，没有时显示“未标记”。
- 当前配音状态，配音功能见 `03-配音-单条与全部配音.md`。

播放逻辑：

- 视频地址优先 `projectService.getMergedVideoUrl(project.id)`。
- 没有合并视频时用 `projectService.getVideoStreamUrl(project.id)`。
- 选择脚本行后，播放器 seek 到 `segment.start_time`。
- 播放到 `segment.end_time` 自动暂停。
- 用户再次点击播放，从 `segment.start_time` 重新播放。

### 4. 右侧脚本列表

列表字段：

- 序号。
- 开始时间。
- 结束时间。
- 类型：`OST=0` 显示“单独配音”，`OST=1` 显示“原片声音”。
- 解说文本。
- 当前 `shot_id`。
- 配音状态。
- 操作按钮：预览、选择镜头、单条配音。

交互：

- 点击行选中并播放该行。
- `OST=1` 行不显示单条配音按钮。
- 选择镜头后立即更新当前行 `start_time/end_time/shot_id/shot_source`，但仍需点击保存按钮持久化。

### 5. 镜头选择弹窗

弹窗布局：

- 顶部：当前脚本行摘要。
  - 当前时间段。
  - 当前时长。
  - 当前文本。
  - 已选镜头信息。
- 左侧：候选镜头预览播放器。
  - 点击候选只预览，不替换。
  - 播放区显示待选镜头时间段和时长。
  - 提供“使用此镜头”按钮。
- 右侧：候选镜头列表。
  - `推荐镜头` 分区，展示最多 30 个。
  - `其它镜头` 分区，展示剩余全量镜头。
  - 支持按 `shot_id`、字幕、摘要搜索。

候选卡片字段：

- 排名或 `shot_id`。
- 时间段和时长。
- 分数：优先 `final_score`，否则 `score`。
- 字幕。
- 视觉摘要。
- 匹配原因。
- 当前预览中状态。
- 已应用状态。

确认规则：

- 点击“使用此镜头”后：
  - `segment.start_time = shot.start`
  - `segment.end_time = shot.end`
  - `segment.shot_id = shot.shot_id`
  - `segment.shot_source = "manual"`
- 弹窗关闭，脚本列表选中行保持不变，左侧播放器切换到新时间段。

### 6. 状态与错误

- `shot-options` 加载中：选择镜头按钮显示 loading 或禁用。
- `shot-options` 加载失败：脚本仍可编辑和保存，镜头选择按钮提示错误。
- 推荐候选为空：隐藏推荐区或展示“暂无推荐镜头”，其它镜头仍可选。
- 全量镜头为空：提示先完成 Omni 多模态管线。

## 验收标准

- Omni 项目显示新工作区，非 Omni 项目仍使用原通用脚本编辑器。
- 点击脚本行能播放对应片段。
- 选择镜头弹窗中，推荐镜头排在其它镜头前。
- 点击候选能预览，只有点击“使用此镜头”才替换脚本时间段。
- 保存后刷新项目，替换后的时间段仍存在。
