# 联调与验收清单：Omni 镜头选择与配音

## 环境准备

- 创建或打开一个 `project_type === "omni"` 的项目。
- 项目已上传视频。
- 已完成 Omni 多模态管线，存在 `omni_multimodal_json_path`。
- 已完成镜头匹配或全链路脚本生成，存在 `omni_shot_match_rerank_path` 或 `omni_global_path_search_path`。
- 项目已有 `project.script.segments`。
- 已配置可用 TTS。

## 后端验收

- `GET /api/projects/{project_id}/omni/generate-script/shot-options`
  - 返回 HTTP 200。
  - `data.segments.length` 与当前脚本段数一致或可解释。
  - 每个 segment 有 `preferred_shots` 和 `other_shots`。
  - `preferred_shots.length <= 30`。
  - 返回字段不包含 embedding。
- 单条配音接口：
  - `OST=0` 成功生成并写回 segment。
  - `OST=1` 返回明确错误。
  - 文本为空返回明确错误。
- 一键全部配音接口：
  - 任务进度可查询。
  - manual 音频不被覆盖。
  - bulk 音频可重新生成。

## 前端验收

- 进入生成步骤，Omni 项目显示新脚本工作区。
- 左侧播放器可播放当前脚本片段。
- 点击右侧脚本行后：
  - 行选中状态变化。
  - 左侧片段信息变化。
  - 播放器 seek 到对应时间段。
- 点击“选择镜头”：
  - 弹窗打开。
  - 推荐镜头展示在其它镜头之前。
  - 点击候选只预览，不修改脚本。
  - 点击“使用此镜头”后才修改当前 segment。
- 保存脚本后刷新页面，替换后的时间段和 `shot_id` 保留。

## 配音验收

- 单条配音：
  - 按钮 loading 状态正确。
  - 成功后可试听。
  - segment 标记为 `tts_source = manual`。
- 一键全部配音：
  - 显示任务进度。
  - 已有有效 manual 的条目保持不变。
  - 无配音和 bulk 条目生成或更新音频。
- 文本变更：
  - 旧配音显示“需重新配音”。
  - 重新配音后状态恢复正常。

## 下游回归

- 生成视频：
  - OST=0 且有有效 `tts_audio_path` 的片段不重新 TTS。
  - 无有效 `tts_audio_path` 的片段保持现有临时 TTS 逻辑。
  - OST=1 保留原片声音。
- 生成剪映草稿：
  - 音频轨使用有效配音文件。
  - 时间线能正常打开。
  - 原声片段不被错误替换为配音。

## 异常场景

- 没有 `omni_multimodal_json_path`：选择镜头入口禁用并提示先完成 Omni 多模态管线。
- 没有推荐候选：推荐区显示空态，其它镜头仍可选。
- TTS 配置不可用：配音按钮报错但不影响脚本编辑和保存。
- JSON 解析失败：显示原始 JSON 编辑兜底，不丢用户内容。
- 网络或接口失败：保留当前编辑状态，提示重试。

## 完成定义

- 后端接口、前端交互、配音复用和下游生成全部通过上述验收。
- 非 Omni 项目行为不变。
- 旧项目没有新增字段时能正常打开。
- 新增字段不会破坏现有 `/script` 保存和视频生成。
