# 🚀 方案三：引入“时间窗口（Window Constraint）”（非常有效🔥）

---

## 🎯 核心思想

```text
每一段文案，只允许在“某个时间范围内选镜头”
```

---

## ✅ 定义窗口

```ts
function getTimeWindow(index, total, duration) {

  center = (index / total) * duration

  return {
    min: center - 120,
    max: center + 120
  }
}
```

---

## ✅ 过滤候选

```ts
function filterByTimeWindow(candidates, window) {
  return candidates.filter(c =>
    c.start >= window.min &&
    c.start <= window.max
  )
}
```

---

👉 效果：

```text
item4（第5段） → 不可能选到 511s
```

# 🚀 方案四：Step6 增强 transition penalty（推荐🔥）

---

```ts
function calcTransitionScore(prev, curr) {

  let score = 0

  gap = curr.start - prev.end

  // 正常
  if (gap >= 0 && gap < 30) score += 1

  // 过大跳跃
  if (gap > 120) score -= 2   // ⭐ 强惩罚

  // 时间倒退
  if (gap < 0) score -= 3     // ⭐ 极强惩罚

  return score
}
```
